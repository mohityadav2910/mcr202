# Submission & Platform Operation Guide
**Project**: Interactive Specific Heat Capacity (Cp vs. T) Platform
**Coursework Compliance**: Meets requirement to submit working dashboard/executable rather than raw script files.

---

## 1. How to Launch and Run the Platform
### Option A: Direct Web Dashboard (Recommended for grading / presentations)
1. Navigate to the dist/ folder in this submission directory.
2. Double-click dist/index.html.
3. The platform opens instantly in any modern web browser (Edge, Chrome, Safari, Firefox).
4. **Zero installation or server required**: All 200 materials, plotting libraries, and thermodynamic algorithms are 100%% self-contained.

### Option B: Native MATLAB Desktop Application
1. Open MATLAB.
2. In the MATLAB Command Window, run:
   addpath('src');
   CpExplorer;
3. The interactive graphical user interface will initialize with full multi-curve and category support.
