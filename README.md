# Interactive Specific Heat Capacity (Cp vs. T) Platform
Thermodynamic Database & Comparative Analysis for 200 Engineering Materials.

## 🚀 Live Demo
Access the live web application on GitHub Pages:
**[https://mohityadav2910.github.io/mcr202/](https://mohityadav2910.github.io/mcr202/)**

## 📖 Features
- Full thermodynamic NIST Shomate parameter calculations across 200 materials.
- Interactive multi-curve plotting and dynamic temperature range adjustments.
- Comparative enthalpy integration ($\Delta H$) and thermal performance ranking tables.
- Data export in CSV and high-resolution PNG formats.
- Dual execution: 100% self-contained web platform (`dist/index.html`) and native MATLAB GUI (`src/CpExplorer.m`).
